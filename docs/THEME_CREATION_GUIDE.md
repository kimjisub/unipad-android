# UniPad Theme Creation Guide

The theme guide now lives on the UniPad website, in English and Korean:

- English: <https://unipad.io/docs/theme>
- 한국어: <https://unipad.io/ko/docs/theme>

It covers the ZIP layout, `theme.json`, every image the play screen reads,
the Pro Light Mode logo (`logo_led.png`), `colors.json`, import checks, and
where the Android app, the iOS app and the web player differ. The same theme
ZIP works in all three.

The website page is the only copy that is kept up to date. This file stays so
that links from older app versions still lead to it.
